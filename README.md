# Kitapp

Кыргызча электрондук китеп дүкөнүнүн MVP-версиясы. Үч бөлүктөн турат:

| Бөлүк | Папка | Технология | Порт |
|---|---|---|---|
| Окурмандар үчүн тиркеме | `lib/`, `web/` | Flutter Web + Readium | 8083 |
| API | `server/` | NestJS + Prisma + PostgreSQL | 3000 |
| Админка | `admin/` | React + Vite | 5173 |

PostgreSQL Docker ичинде `127.0.0.1:55432` портунда иштейт. Китеп файлдары `server/storage` папкасында сакталат.

## Биринчи жолу орнотуу

Талаптар: Node.js, Flutter, Docker Desktop.

```bash
npm install
docker compose up -d
cp server/.env.example server/.env
npm --workspace server run db:migrate
npm --workspace server run db:seed
```

## Иштетүү

Ар бир буйрукту өзүнчө терминалда иштетиңиз.

1. API:

   ```bash
   npm run dev:server
   ```

2. Админка:

   ```bash
   npm run dev:admin
   ```

3. Окурмандар үчүн тиркеме:

   ```bash
   flutter run -d web-server --web-port 8083
   ```

| Эмне | Дарек | Кирүү |
|---|---|---|
| Админка | http://127.0.0.1:5173 | `admin@kitapp.kg` / `Kitapp123!` |
| Редактор | ошол эле админка | `editor@kitapp.kg` / `Editor123!` (`EDITOR_EMAIL` коюлса) |
| Тиркеме | http://127.0.0.1:8083 | каалаган телефон, SMS-код `111111` |
| API | http://127.0.0.1:3000/api | — |

### 3000-порт бош эмес болсо

API'ни башка портто иштетип, админка менен тиркемеге жаңы даректи бериңиз:

```bash
cd server && npm run build && PORT=3100 PUBLIC_URL=http://127.0.0.1:3100 node dist/src/main.js
```

```bash
cd admin && VITE_API_URL=http://127.0.0.1:3100/api npx vite --host 127.0.0.1 --port 5173
```

```bash
flutter run -d web-server --web-port 8083 --dart-define=KITAPP_API_URL=http://127.0.0.1:3100/api
```

## Админка

Дизайн окурмандар тиркемеси менен бирдей: ак-кагаз фон, бир жашыл түс, Golos Text жана Literata шрифттери. Барактын дареги URL'де сакталат (`#/books`, `#/books/<id>`), ошондуктан барак жаңырганда ошол жерде калат.

| Барак | Эмне кылат | Ким көрөт |
|---|---|---|
| Башкы бет | Каталогдогу китептер, окурмандар, сатуулар жана киреше. Мукабасы, EPUB'у же сүрөттөмөсү жок китептердин тизмеси. Акыркы төлөмдөр жана айдын эң кирешелүү китептери. | Баары (акча маалыматы башкы админге гана) |
| Китептер | Мукабалары менен тизме, аталышы же автору боюнча издөө, статус жана жанр боюнча чыпка. Китеп капталдагы панелде ачылат: мукаба алдын ала көрүнөт, файлдар алмашат, жаңы автор ошол жерден кошулат, жеткиликтүүлүк тандалат (сатып алуу, ижара гана, акысыз), жарыялоо жана архив. | Баары |
| Авторлор жана жанрлар | Кошуу, ошол жерде атын өзгөртүү, өчүрүү, авторлорду издөө. | Баары |
| Окурмандар | Телефон же аты боюнча издөө, активдүү/бөгөттөлгөн чыпкасы. Бөгөттөөдө себеби жазылат. | Башкы админ |
| Төлөмдөр | Сатуулар жана ижаралар, издөө, чыныгы статус (ижаранын мөөнөтү канча калганы). | Башкы админ |
| Отчёт | Даяр мезгилдер (бул ай, өткөн ай, 7 күн, 30 күн, бул жыл) же өз даталар. CSV жүктөп алуу (Excel ачат). | Башкы админ |
| Аракеттер журналы | Акыркы 200 аракет, күндөр боюнча топтолгон, түрү боюнча чыпка. | Башкы админ |

Ролдор: **башкы админ** (SUPERADMIN) баарын көрөт. **Редактор** (EDITOR) китептер, авторлор жана жанрлар менен гана иштейт.

## Окурмандар тиркемеси

- Каталогду кирбей эле көрүүгө болот. Сатып алуу, ижара же окуу үчүн телефон менен кирүү керек.
- Кирүү экранында классикалык китептердин мукабалары айланат.
- Окулуп жаткан жер серверде сакталат жана башка түзмөктө улантылат.
- Окуу барагы: мазмуну, белгилер, китептен издөө, 4 тема, шрифт жана өлчөм.

## Текшерүүлөр

```bash
npm run check      # API жана админканы курат
npm run qa:api     # API сценарийлери, өзүнчө kitapp_test базасында
npm run qa:admin   # админканын браузердеги сценарийлери (API жана админка иштеп турушу керек)
flutter analyze
flutter test
```

`qa:admin` Brave браузерин колдонот. Башка Chromium браузери үчүн `BRAVE_PATH` коюңуз. API же админка башка дарекде болсо, `KITAPP_ADMIN_URL` коюңуз.

Эскертүү: `qa:admin` иштеп жаткан базада сыноо китебин жана авторун түзүп, андан кийин архивге жиберет жана өчүрөт. Бир окурманды бөгөттөп, кайра бөгөттөн чыгарат.

## Тест китептер

`tool/load_public_domain_books.cjs` Project Gutenberg'ден коомдук домендеги китептерди жүктөйт (ар бир жеткиликтүүлүк түрү менен). API башка портто болсо, `KITAPP_API_URL` коюңуз.

## MVP чектөөлөрү

- Окурман телефон номери аркылуу гана кирет. SMS шлюзу азырынча тандала элек: `SMS_PROVIDER=log` коду серверден журналга жазат.
- Төлөм чыныгы эмес: `PAYMENT_MODE=local` сатып алууну дароо аяктайт. Ишке киргизүүдөн мурун төлөм провайдери керек.
- Тиркеме веб үчүн гана. iOS жана Android'де «колдоого алынбайт» деген билдирүү чыгат.
- Интерфейс кыргыз тилинде.
